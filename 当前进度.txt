三、v2.1 新增功能
═══════════════════════════════════════════════════════════════

多模型支持：
  ✅ 12 供应商注册表（DeepSeek/通义千问/文心/豆包/Kimi/GLM/星火/MiniMax/GPT/Claude/Gemini/Mistral）
  ✅ Claude Messages API 特殊适配（x-api-key + content_block_delta SSE）
  ✅ 其余 11 家 OpenAI 兼容格式统一处理
  ✅ 全部 API 调用动态路由（0 个硬编码 DeepSeek URL）
  ✅ 自动迁移旧 apiKey/modelName 为 DeepSeek 供应商
  ✅ 模型列表全部更新为 2026 年 8 月最新

Dock 自定义：
  ✅ 长按 Dock 图标 → 弹出替换面板（500ms，10px容忍度）
  ✅ 配置存 localStorage pent_dock，持久化
  ✅ document 级事件委托（不用内联 handler，避免引号地狱）

模型管理页面（设置 → AI 模型管理）：
  ✅ 供应商列表 + 切换
  ✅ API Key 管理
  ✅ 模型选择 + 手动添加
  ✅ 自动拉取模型（Kimi/GPT/Mistral）
  ✅ 测试连接
  ✅ 从 Phone 设置弹窗一键跳转

Phone 设置简化：
  ✅ 弹窗只保留 Temperature/TopP
  ✅ 模型和 Key 统一在设置管理
