# 📱 Phone Desktop — 手机桌面模拟器

> 纯前端 · 单文件 · 零依赖 · 双击就能用

给 AI 聊天应用加一个完整的手机桌面操作系统层。打开是一个手机桌面——锁屏、小组件、22 个 App、7 个小游戏、通知、壁纸、主题切换。点 Phone 图标进入完整 AI 聊天应用。

## ✨ 功能

### 系统层
- 🔒 锁屏界面（点击解锁，时钟+日期，深蓝渐变背景）
- 🏠 多页桌面（图标网格，4×6 布局，滑动翻页）
- 📌 底部 Dock 栏（可自定义）
- 🧩 桌面小组件（时钟、天气、日历、待办、便签）
- 📂 文件夹管理（点选式归类）
- 🎨 主题切换（深蓝 / 暗黑 / 浅色）
- 🔍 全局搜索（搜 App 名、联系人）
- 🔔 通知系统（顶部横幅 + 通知中心 + 桌面角标）

## 🚀 使用

### 浏览器
直接用浏览器打开 `p-ent-phone.html`。

### Android APK
用 HBuilder X 打包（HTML5+），或直接安装 `assets/` 目录下的 APK 文件。

### 首次使用
1. 点 🔒 锁屏解锁
2. 点 ⚙️ 设置 → 填入 DeepSeek API Key
3. 点 💬 Phone 开始聊天

## 🛠 技术栈

- **纯前端三件套**：HTML + CSS + JavaScript
- **存储**：IndexedDB（pent_db_v1）+ localStorage
- **AI**：DeepSeek API（Chat Completions，流式 + 非流式）
- **打包**：HBuilder HTML5+（`plus.io` / `plus.share` 原生能力）
- **零依赖**：无框架、无构建工具、无 npm
